# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues or discussions.

Submit reports through [GitHub's private vulnerability reporting form](https://github.com/Novejuro/Nexora/security/advisories/new). Include a description of the affected code, the potential impact, and steps to reproduce the issue. Avoid sending secrets or real user data. If the form is unavailable, contact the repository owner privately through the [Novejuro GitHub profile](https://github.com/Novejuro).

This is an early-stage project and does not yet publish supported release versions or response-time commitments. The maintainers will update this policy as the project matures.
